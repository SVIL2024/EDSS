# EDSS documentation

The public documentation is deliberately limited to the method, the evidence
reported with it, known limitations, and reproducibility instructions.

- [`METHOD.md`](METHOD.md): training objective, evidence construction, and
  inference behavior.
- [`RESULTS.md`](RESULTS.md): measured results, references, and claim scope.
- [`LIMITATIONS.md`](LIMITATIONS.md): calibration, protocol, and comparison
  caveats.
- [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md): clean-release boundary and
  reproduction checklist.

Private working notes, superseded experiments, raw analysis outputs, and
session transcripts are not part of the public repository.
